          Keyboard shortcuts
          
    
          
      
          V / Escselect tool (Esc also clears the selection)
          
      
          R C Prectangle / circle / lumped-port tool
          
      
          Ttransmission line — click centerline points, Enter closes; hover a line to read its length
          
      
          Xmeasure tool — drag between two points
          
      
          Nnote — click to place; click its triangle (or double-click) to collapse/expand
          
      
          G / M / Ftoggle grid / mesh preview / fit view
          
      
          Ctrl+C/X/Vcopy / cut / paste the selection
          
      
          Ctrl+Dduplicate
          
      
          Ctrl+Aselect all objects
          
      
          Deldelete the selection
          
      
          arrowsnudge the selection by one snap step
          
      
          drag on emptybox-select every object inside
          
      
          wheel / mid-dragzoom / pan the canvas
          
      
          Enterclose the polygon being drawn
